# Task 16 - Student Directory

A responsive student directory that demonstrates JavaScript array `map()` and
`filter()` methods.

## Features

- Renders student cards from a single data array with `map()`.
- Searches student names, marks, classes, and addresses with `filter()`.
- Supports case-insensitive, partial matches and searches as you type or when
  you press Search/Enter.
- Shows the result count and a helpful message when there are no matches.
- Clear resets the search and restores the complete student list.
- Responsive layout for desktop, tablet, and mobile screens.

## Run

Open `index.html` in a web browser. No build tools or dependencies are needed.
